# SaldoNest — версия 1.2

- добавлен полноэкранный immersive-режим;
- строка состояния Android с часами, Wi‑Fi, сетью и батареей скрывается при открытии приложения;
- нижняя системная панель навигации также скрывается;
- системные панели можно временно вызвать свайпом от края, после возвращения в приложение они снова скрываются;
- сохранены исправления версии 1.1: суммы с запятой/точкой и быстрое добавление категорий из окна операции.

# SaldoNest — версия 1.1

Изменения:

- суммы теперь можно вводить как через запятую, так и через точку: `4658,77` и `4658.77`;
- рядом с полем суммы добавлена отдельная кнопка `,`, поэтому десятичную запятую можно ввести даже если клавиатура телефона показывает только точку;
- при создании расхода или дохода можно сразу нажать **«+ Добавить свою категорию»** и создать новую категорию, не переходя в Настройки;
- новая категория сразу выбирается для текущей операции и сохраняется для будущих операций;
- то же быстрое добавление категории доступно при редактировании операции;
- прежнее управление категориями через Настройки сохранено.

Версия Google Play: 1.1
Внутренний versionCode: 14

# SaldoNest — версия 1.0

Это новая точка отсчёта версий приложения.

- Видимая версия приложения: **1.0**.
- Внутренний Android `versionCode`: **13** — он специально продолжает расти, чтобы APK можно было устанавливать поверх предыдущих сборок без удаления данных.
- С этого релиза дальнейшие пользовательские версии будут идти как 1.1, 1.2, 1.3 и т. д.
- Сохраняются все функции последней сборки: 3 вкладки, адаптивный интерфейс, темы и акценты, редактирование/удаление операций, все операции, пользовательские категории, Excel, резервное копирование/восстановление, прозрачная иконка и подготовка к публикации.
