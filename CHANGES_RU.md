# Finup — версия 1.6.1

- добавлена явная кнопка **«Удалить»** в окне редактирования любой операции;
- перед удалением показывается подтверждение с категорией и суммой;
- после удаления баланс, отчёты и списки обновляются сразу.

# FinFlow / Finup — версия 1.6

Что улучшено:

- обновление поверх старой версии теперь сохраняет данные — не нужно удалять приложение;
- в настройках можно сохранить **лог / резервную копию** всех операций в файл JSON на телефон;
- на другом телефоне можно открыть этот файл и **восстановить операции, счета, категории, валюту и бюджет**;
- верхний заголовок **«Мои Финансы»** на главной странице убран;
- главная страница стала более простой и интуитивной: большой баланс, быстрый обзор, кнопка добавления и ниже счета/структура расходов;
- обновлён логотип приложения;
- имя приложения приведено к более короткому виду: **Finup**.

Как обновлять без потери данных:
1. не удаляйте старую версию приложения;
2. установите новую APK **поверх** старой;
3. если нужно перенести данные на другой телефон, сначала сохраните JSON-резервную копию в настройках, затем откройте её на новом устройстве через пункт восстановления.
