# Finup — версия 1.7

Что изменено:

- в главной вкладке верхняя дата сделана аккуратнее: теперь это компактный красивый бейдж с месяцем;
- во вкладках **Операции**, **Отчёты** и **Настройки** убраны большие верхние заголовки;
- добавлен раздел **Оформление** в настройках;
- можно выбрать тему приложения: **тёмная / светлая / системная**;
- можно выбрать цвет логотипа и акцентных иконок интерфейса: **мятный / синий / фиолетовый / коралловый**;
- переработан логотип приложения;
- сохранены все прошлые функции: редактирование и удаление операций, свои категории, отчёты, экспорт в Excel, резервное копирование и восстановление данных.

Обновление без потери данных:
- устанавливайте новую APK поверх старой версии;
- не удаляйте приложение перед обновлением;
- для переноса данных на другой телефон используйте резервную копию JSON в настройках.
