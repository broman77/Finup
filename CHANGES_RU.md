# FinFlow — версия 1.4

## Новое

- Полностью настраиваемые категории расходов и доходов.
- Можно создавать собственные категории.
- Можно переименовывать категории.
- Можно удалять ненужные категории.
- При переименовании категории старые операции автоматически получают новое название.
- При удалении категории старые операции не удаляются: категория лишь исчезает из списка для новых операций.
- Нельзя удалить последнюю категорию каждого типа, чтобы форма новой операции всегда оставалась рабочей.
- В «Настройки» добавлен отдельный красивый блок «Категории» со счётчиками расходов и доходов.
- В форме операции есть подсказка, где настраивать категории.

## Уже доступно из прошлых версий

- несколько счетов;
- редактирование и удаление операций;
- отчёты за месяц, год и произвольный период;
- графики и разбивка расходов по категориям;
- месячный бюджет;
- экспорт всех операций в настоящий Excel `.xlsx`;
- резервная копия JSON;
- офлайн-работа без регистрации.
