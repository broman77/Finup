# Как собрать APK прямо на сайте GitHub

Проект уже содержит автоматическую сборку `.github/workflows/build-apk.yml`.

1. Создайте аккаунт на GitHub, если его ещё нет.
2. Создайте новый репозиторий. Можно выбрать **Private**.
3. Распакуйте этот ZIP на компьютере.
4. В новом репозитории нажмите **Add file → Upload files**.
5. Загрузите **содержимое папки `FinFlowAndroid`**, чтобы в корне репозитория были `app`, `.github`, `build.gradle.kts`, `settings.gradle.kts` и остальные файлы.
6. Нажмите **Commit changes**.
7. Откройте вкладку **Actions**.
8. Выберите **Build APK**.
9. Нажмите **Run workflow → Run workflow**.
10. После успешной сборки откройте выполненный запуск. В разделе **Artifacts** скачайте **Moi-Finansy-APK**.
11. GitHub скачает ZIP-архив. Распакуйте его — внутри будет `app-debug.apk`.
12. Перешлите `app-debug.apk` на Samsung Galaxy A56 и откройте файл на телефоне. Android может попросить разово разрешить установку приложений из этого источника.

`app-debug.apk` подписывается стандартным debug-ключом Android и подходит для личного тестирования/установки. Для публикации в Google Play нужно отдельно создать release-подпись.
